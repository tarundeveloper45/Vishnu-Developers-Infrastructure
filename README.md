# Vishnu Developers static website

This is a normal HTML, CSS and JavaScript website. It does not require Node.js.

## Review locally

Open `index.html` directly, or in VS Code install **Live Server**, right-click `index.html`, and choose **Open with Live Server**.

## Content updates

Repeated company, contact, brochure and floor-plan data is stored in `config.js`. Replace all values marked “to be confirmed” only after the client provides verified information.
